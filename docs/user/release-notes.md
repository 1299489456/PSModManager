## 本地模组检查与受控启动

- 可显式请求本机 Defender 检查，单独展示引擎结果与不可用状态。基础检查不需要 AI，也不上传给第三方分析服务；Defender 云保护受系统设置控制。
- 继续保留启用时不弹权限框、权限在详情查看的约定。未发现高风险仅表示本次静态规则结果，不作为安全认证。

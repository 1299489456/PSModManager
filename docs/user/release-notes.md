# 0.1.0 便携版

2026-10-19（公开发布）：README 增加真实配置的模组、方案和 Nexus 界面截图；GitHub Releases 提供 Windows x64 便携 ZIP。版本标签触发自动构建、包体检查与发布。公开包保留 Cpp2IL 和配套插件的离线恢复，不再分发 Unity 运行库；Unity 生成依赖由 MelonLoader 首次运行时下载。本地完整资源构建仍可用。

2026-10-19（Nexus 与许可页更新）：Nexus 列表改用 Nexus 的分页接口，可浏览本游戏全部 Mod，向下滚动自动加载，支持按名称搜索和四种排序；卡片显示封面、分类、版本、作者、下载与赞同数。点击卡片进入详情页（主图、统计、标签、前置需求、文件列表、完整介绍），介绍可用已配置的 AI 服务翻译为中文，原文随时切回；官网链接放在详情页底部。界面只从 Nexus 自己的图片服务器加载图片。“应用信息”新增“许可与致谢”：MIT 许可全文、版权与商标声明、数据与隐私、功能、主要开源组件及其许可、外部工具与服务、第三方说明全文；其他界面不再出现参考项目的名称。

2026-10-16（第三次界面更新）：顶栏改为“模组 · 方案 · Nexus · 日志 · 应用信息”，方案和 Nexus 都是独立页面。方案页左侧列出全部方案，右侧显示所选方案：未修改时只有“应用到游戏”，修改后出现“保存”与“另存为…”，其余操作收进“更多（⋯）”；“替换保存”改为“保存”。Nexus 页按温室样式重做（账户状态、列表切换、卡片与文件列表）。智能分析的对话改为头像 + 气泡排版，状态提示集中在输入框上方，附带内容收进输入框的附件标签。所有弹出面板都可以点周围变暗的区域关闭。

2026-10-16（反馈修复版）：修复冷启动自动发现命令被前端桥接拒绝而显示“无法完成安装操作”；已覆盖首次选择、保存安装重开与切换。智能分析在有限查询后预留最终结论，重复查询复用结果，工具前的详细分析不再被末轮短回复覆盖。

保存当前列表不再重复读取全包库内容；1912 文件、86.6 MiB 的等量合成布局再次保存从 3.80 秒降至 0.69 秒，首次建立恢复副本从 20.07 秒降至 13.05 秒，并显示文件进度。修复正常资源文件 `secret_admirer.png` 被误判为凭据；导出仍校验文件内容，拒绝时指出具体 Mod、路径与类别。Nexus 获取 Key 改用当前官网 API Key 设置页，先官网登录再生成或复制个人 Key，当前仍为个人 Key 接入。

本轮已使用已配置的真实 `deepseek-flash` 服务，仅发送合成日志：完成环境与 Mod 查询、分析结论、被动建议卡、合成环境确认停用及追问核对，最终通过的完整运行包含 5 次服务请求。另在实际 WebView 验证多轮分页、查询收束、长回复、取消、继续和建议启停；这些结果不代表真实游戏修复或所有模型均已验证。

2026-10-16（方案与智能分析更新）：可将当前已保存列表新建/覆盖为 Mod 方案，修改后另存，导出清单或包含具体版本与文件的整合包，并在另一套管理器导入应用。拖入 DLL/目录/ZIP 时识别同一 Mod 的新旧版本，确认后升级或降级，保留旧版本与方案引用。根说明文档保留在包库，随整合包分享，不部署到游戏。

导航“日志与 AI”改为“日志”，“AI 排错”改为“智能分析”。修复普通中文长回复和大量 SSE 分片触发显示超限；中断或取消后保留文本并支持手动继续。新增本游戏专用环境提示、工作区查询和外部 Mod 启停建议，用户确认后执行并刷新主列表。排序仍以 MelonLoader 的实际依赖与 DLL 优先级为准。

新增“在线 Mod”个人 Key 接入：浏览 Nexus 的本游戏最近/热门列表、选择文件、授权下载并进入现有版本预览/安装流程。普通账户使用官网 Manual download，下载后回到管理器导入；仅当官网提供管理器下载按钮时才使用 NXM 接收。Premium 可直接下载。接入与公开分发条件见[方案、更新与在线 Mod](sharing-updates-online.md)。

2026-10-16（第二次更新）窗口使用与界面一致的自绘标题栏（PSMM，可拖动、双击或按钮最大化，边缘可调整大小，最大化不遮挡任务栏）；模组页新增搜索、排序、卡片／列表切换和分页；日志改为向上滚动自动加载；界面文字改为更直接的说法，界面内名称显示为 PSMM，版本号在“应用信息”中查看。

2026-10-16 界面改为单一的“温室”浅色样式：顶栏导航、MelonLoader 状态、游戏安装牌子和太阳启动按钮；Mod 以卡片展示，开关后的更改收进“待保存”篮子，点击卡片原位展开详情，卸载在卡片内确认；日志页改为笔记本样式。移除主题切换和加载列表拖动排序，文件操作与保存流程不变。

此前的统一 Mod 工作区：左侧详情、中间 Mod 库、右侧加载列表。已有 Mod 自动按 DLL 与关联资源分组，拖拽启停、多选、撤销、保存及保存后启动在同一页完成；不再显示重复的“游戏文件”与包库管理页面。启动时自动查找 Steam 游戏库，也可手动选择目录，不要求完整游戏指纹。

普通 Mod 保存、启停和卸载改为轻量文件处理，取消逐文件事务刷盘与反复全库校验，不增加“快速／安全模式”。保留目标边界、外改保护和整次操作的恢复记录；已有包库、管理状态及旧部署记录继续使用。130 文件合成样本的完整启停调用已降至约 1 秒，1863 文件的实际桌面合成操作约 6–8 秒；真实 Mod 的耗时仍取决于文件大小、数量和磁盘。

“日志”并排展示原文与智能分析，提供连续日志阅读、查找、错误过滤、可核对的发送资料、流式分析、取消、继续和追问。打开页面或保存服务设置不会联系 provider。Mod 方案与配置仍为可选功能。运行依赖：Windows 10/11 x64、.NET Framework 4.8+、WebView2 Runtime；Python 和 helper 的 .NET 运行时随包携带，不要求开发 SDK。

选择游戏后自动显示 MelonLoader 安装和运行环境状态；用户可点击下载并安装官方 0.7.3 Windows x64 包，也可从该版本官方 ZIP 本地安装。普通 Mod 操作不等待加载器安装；系统运行库通过环境详情中的官方链接手动安装。重装保留现有 Mod 和配置，不会自动启动游戏。

便携包包含中文使用说明、项目/第三方版权材料及完整文件清单。便携根有 `README-PORTABLE.txt`、`LICENSE`、`THIRD_PARTY_NOTICES.md`、`build-manifest.json`、`SHA256SUMS.txt`、`licenses/` 与 `docs/user/`；具体程序字节和本次验证范围以对应构建清单、修复报告为准。

本轮在实际 WebView 中使用合成游戏与 localhost AI 服务，验证了多文件 Mod 启停、保存后启动、卸载后恢复、日志分析与追问。另以 C 盘数据目录、E 盘合成游戏验证跨盘事务与崩溃恢复。便携包检查和完整证据见对应构建报告。

保存前请正常关闭游戏。特殊启动器、改名或已删除映像的硬链接、非主映射句柄及部分原生查询竞态仍有运行中检测缺口；历史守卫回归的 8 项失败保留在报告中。

干净机器、独立标准账户、物理缺运行时的新机器、真实用户旧数据迁移和真实游戏玩法未测。真实 AI 的合成日志链路已测；真实 Nexus 账户授权和下载未测。不支持后台自动更新、正式存档管理、一键整目录数据恢复或一键清空未知 Mod 文件。所有在线获取与写操作均由用户主动触发。

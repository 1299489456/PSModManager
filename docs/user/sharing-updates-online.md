# 分享一套 Mod，或替换其中的版本

## 把当前列表保存给自己或朋友

1. 在“模组”页完成启停选择并点击“保存”。有未保存草稿时，先保存或撤销。
2. 打开顶栏的“方案”页，点“新方案”，输入名称并选“当前模组列表”；要替换原方案，在左侧选中它，再从“更多（⋯）”选“用当前模组列表覆盖”。方案修改后的“保存”和“另存为…”分别保留原方案或创建副本。
3. 导出时选择清单 JSON 或包含 Mod 的完整 ZIP。JSON 适合对方已有相同版本的情况；完整 ZIP 携带方案固定的具体版本及文件。
4. 对方选择自己的游戏，拖入分享 ZIP/JSON，或在“方案”页点“导入”。先查看启用状态、版本、缺失项与冲突，再点击“导入并应用”。仅导入包库而不应用时，游戏文件保持不变。

分享包不包含游戏本体、存档、账号密钥或管理器配置。根目录 README 等说明附件保存在包库并随包分享，不部署到游戏。分享前确认各 Mod 作者允许再分发；不允许的内容可只分享清单。

完整包最多 4000 个文件、1 GiB 内容，不能包含脚本、可执行程序、危险路径或篡改内容。清单缺少对应版本时会指出缺失项，不会用另一个版本悄悄顶替。

## 拖入新版升级，也能拖入旧版降级

拖入 DLL、目录或普通 ZIP，先看 Mod 身份与版本关系。管理器优先读取 DLL 内嵌标识；文件名版本仅作提示，只有相同目标等弱关联时需要你确认是否属于同一 Mod。

点击“添加到包库”后，再使用“安装 / 更新到游戏…”查看将替换的版本，最后确认安装或替换并启用。替换会处理旧版独有的已知文件，保留其他 Mod、未知文件和存档；发现旧文件被外部修改时停止并提示。旧版仍在包库，已有方案继续引用原版本。

普通 ZIP 保留 64 MiB、展开总计 256 MiB、4000 文件限制。分享整合包使用前一节的独立入口，不会被普通 ZIP 大小限制误挡。多文件拖入按队列逐个预览，不会自动批量写入游戏。

## 从 Nexus 获取 Mod

1. 打开顶栏的“Nexus”页，在“连接你的 Nexus 账户”中点击“登录并获取 Key”，打开 [Nexus API Key 设置](https://www.nexusmods.com/settings/api-keys)。未登录时先在官网登录，再生成或复制个人 API Key，回到管理器填写。遇到官网安全验证时在浏览器完成验证。不要把密钥贴到聊天或随方案分享；可选保存到 Windows 凭据或仅本次使用。
2. 点击“加载列表”。列表包含本游戏在 Nexus 上的全部 Mod（不含成人内容），可按“最近更新”“最新发布”“下载最多”“最受好评”排序，或在搜索框按名称查找；向下滚动会自动加载下一页。
3. 点击卡片进入详情页：主图、作者、下载与赞同数、标签、前置需求、文件列表和完整介绍。介绍不是中文时，可点“AI 翻译为中文”，译文会分段显示，“原文”可随时切回。翻译使用“日志”页里配置的 AI 服务，只在点击时发送这个 Mod 的介绍。
4. 在文件列表点击“下载”。**Premium 账户**可直接下载。**普通账户**展开“普通账户怎么下载？”，到官网文件页选择使用管理器下载，把 `nxm://` 授权链接粘贴进去再下载。7z、RAR 等压缩包请在官网手动下载并解压后导入。
5. 下载完成会切到“模组”页并打开导入预览。核对 DLL 实际版本与目标文件后，再确认加入包库及安装/更新。详情页最底部的“在 Nexus Mods 打开原页面”可查看评论、图片和更新日志。

下载链接必须属于 `probablystolen`、当前 Nexus 账户及所选文件，且未过期。文件 API 版本与 DLL 内嵌版本可能不同，安装预览以内嵌信息为准；不把未提供依赖信息当成没有依赖。当前接收 ZIP/DLL，最大 64 MiB；下载取消或管理器关闭后会清理本次未再使用的下载原件，不删除已经加入包库的副本。

本接入供个人本地使用。Nexus 要求面向普通用户公开分发前注册应用；当前没有借用其他应用的 Key、SSO 身份或取得公开发行授权。规则见 [Nexus API 使用政策](https://help.nexusmods.com/article/114-api-acceptable-use-policy)，普通账户下载授权见 [Nexus 官方 API 说明](https://github.com/Nexus-Mods/node-nexus-api/blob/master/docs/classes/_nexus_.nexus.md#getdownloadurls)。

# 快速开始

## 打开管理器

完整解压便携 ZIP，再运行 `PSModManager.exe`。不能只取出一个 EXE，也不要移动 `_internal` 或 `PSModManager.WorkerHost.exe`。选择普通用户可写的程序和游戏安装位置；遇到权限不足先处理目录权限，不要求以管理员运行。

运行环境为 Windows 10/11 x64、.NET Framework 4.8+、WebView2 Runtime。Python、Node 和 .NET SDK 不是运行前置；元数据 helper 带自己的 .NET 运行时。缺运行时会提示，不会静默安装。

第一次启动先选择数据位置：可使用默认目录，也可选择 D / E 等其他盘上的独立空目录。后续打开“设置”→“数据位置”→“更换数据目录”，确认后一起迁移包库、方案、配置、缓存和日志，完成后点击重启。游戏文件和存档不会搬动；具体范围与备份清理见[数据与重装](data-and-reinstall.md)。

## 选择游戏

启动时自动查找 Steam 游戏库中的 Probably Stolen；找到一个安装时直接使用，找到多个时选择要管理的安装。没有找到或需要更换时，点击“选择游戏安装”→“手动选择安装目录”，选含 `Probably Stolen.exe` 的游戏根目录，也可通过“选择 Steam 目录”重新查找。

已保存的安装可以再次选择。目录选择只检查路径和游戏可执行文件，不要求生成完整游戏指纹。

## 准备 MelonLoader

选定游戏后，顶栏会显示 MelonLoader 状态；有问题时，“模组”页顶部还会出现提示牌。点击顶栏的状态或提示牌上的“查看环境”，可查看加载器版本与核心文件、游戏和代理 DLL 的 x64 架构、加载器是否被配置停用，以及所需 .NET 和 VC++ 运行库。

没有安装或需要重装时，点击提示牌或环境面板中的“下载安装 MelonLoader 0.7.3”；管理器此时才从官方发布页下载 Windows x64 包并安装。也可在环境详情中点击“从本地 ZIP 安装”，选择 [MelonLoader 0.7.3 官方 x64 ZIP](https://github.com/LavaGang/MelonLoader/releases/download/v0.7.3/MelonLoader.x64.zip)。本地安装只接受该版本的官方原包，不使用 Mod 导入入口。

游戏的 IL2CPP 加载器需要 .NET 6 x64 Core Runtime（Desktop Runtime 也可）和 VC++ x64 运行库；这与管理器自身的运行环境不同。缺少时，通过环境详情中的官方链接自行安装，再点击“重新检测”。管理器不会自动安装系统运行库或启动游戏；重装加载器保留 `Mods` 和 `UserData` 中的现有文件及配置。

MelonLoader 检测与安装不阻止普通 Mod 入库、安装和启停；游戏要加载 Mod，仍需先处理环境状态中显示的问题。

完整便携包提供面向 MelonLoader 0.7.3 的 Cpp2IL `2022.1.0-pre-release.21` 与 Unity `2021.3.45` 生成依赖，不包含 MelonLoader 安装包。安装加载器后会补齐这些依赖；以后通过本管理器启动游戏前，会检查并从本地资源恢复缺失或损坏的 Cpp2IL、配套插件和 Unity 依赖，无需访问 GitHub。也可在环境详情点击“离线修复生成依赖”。原有 Mod、存档和生成配置保持不变。

自定义 Cpp2IL 或其他 Unity / MelonLoader 版本不会被强制替换，环境详情会指出不支持的组合。缺少所需工具时先处理环境，再启动游戏。请完整解压便携包，不要只复制 EXE；从 Steam 直接启动不会经过管理器的启动前检查。

## 在“模组”页管理 Mod

“模组”是主工作区：每个 Mod 是一张卡片，按“包库中的 Mod”和“游戏目录中发现”分组。上方工具栏可以按名称或版本搜索（Ctrl＋F），按全部、已启用、未启用或需处理筛选，按名称、启用状态或文件数排序，并在卡片和紧凑列表之间切换；Mod 较多时按页显示，可选每页 24、48 或 96 个（PageUp／PageDown 翻页）。点击卡片会在原处展开详情和文件树。游戏中已有的 DLL 与同名资源目录会合并为一个 Mod；首次停用时自动保留副本，不需要再进入“接管”页面。

1. 拖入 DLL、目录或 ZIP，或点击“导入”选择文件。
2. 查看包名称、文件、目标目录及提示；需要时改包名称，再点击“添加到包库”。不支持的内容会显示原因。
3. 看到“已添加 Mod”后，可点击“安装 / 更新到游戏…”核对版本并确认安装；也可点击“在列表中查看”，打开卡片右上角的开关。同一 Mod 的新版/旧版会显示升级或降级关系，旧版本保留在包库。
4. 每次开关都会记进右侧的“待保存”篮子。点击“保存”应用变更；也可点击篮子里或右上角太阳按钮的“保存并启动”，管理器会先完成保存，再启动游戏；保存失败时不会继续启动。

导入保存独立副本，不移动、停用或修改来源文件。安装目标限于 `Mods`、`Plugins`、`UserLibs`。游戏中已经存在的 Mod 直接从主列表操作，无需重复导入。

只支持 DLL、目录和 ZIP；不支持 RAR/7z、加密/分卷/嵌套压缩包或安装脚本。单次导入最多 4000 个文件，展开后共 256 MiB；单文件及 ZIP 不超过 64 MiB。工作区单次保存最多 4000 个文件操作。程序不执行包内安装脚本或待分析 DLL。

## 启停和卸载

| 按钮 | 当前行为 |
|---|---|
| 关闭卡片开关，再保存 | 停用整个 Mod，保留包库及安装记录，便于再启用 |
| 打开卡片开关，再保存 | 从包库恢复该 Mod 的安装文件 |
| 全部启用 / 全部禁用，再保存 | 修改整个列表，不受搜索、筛选或分页影响；不可管理项保持不变。同一 Mod 保留已选版本，多版本无法确定时提示单独选择 |
| 展开卡片中的“卸载”→“确认卸载” | 移除该 Mod 的安装成员和独占部署文件；其他 Mod 仍使用的相同共享文件保留，包库副本也保留，卡片显示“未安装”。先保存或撤销当前草稿后使用 |
| 刷新 | 重新读取实际文件和安装状态，不会自动修复或覆盖外部改动 |

开关和批量启停只修改待保存选择；篮子里的“撤销”放弃全部草稿，Ctrl＋Z 撤销上一次操作。展开详情后，点击卡片上方空白处、关闭按钮或按 Esc 即可收起。方向键在卡片间移动，空格启停当前卡片，回车展开，Ctrl＋F 搜索，Ctrl＋S 保存。不提供拖动排序：MelonLoader 的真实加载顺序由加载器决定。

保存前正常关闭游戏。普通 Mod 操作使用轻量文件处理，不需要选择模式或批准计划。操作失败或取消时，管理器尝试恢复本次变更；若提示仍有未完成操作，重新打开管理器，让它读取保留的恢复记录。不要在保存过程中手动改动同一批文件。

## 保存方案或安装整合包

先保存或撤销主列表中的草稿，再打开顶栏的“方案”页：点击“新方案”→“当前模组列表”保存当前已保存的列表；要覆盖已有方案，在“更多（⋯）”中选“用当前模组列表覆盖”。修改方案后点“保存”，或“另存为…”成为新方案，再点“应用到游戏”。“更多”中的“导出整合包（含 Mod 文件）”会带上具体版本和文件；对方拖入 ZIP 或在“方案”页点“导入”，查看清单后“导入并应用”即可。只有 JSON 清单时，对方需先补齐缺少的版本。

在线获取、更新与分享的具体操作见[方案、更新与在线 Mod](sharing-updates-online.md)。

删除不再使用的方案：选中方案，在“更多（⋯）”中点击“删除方案…”，核对名称后确认。删除只移除方案，不卸载游戏里的 Mod，也不删除包库或已部署历史。

## 看日志并用智能分析排错

1. 打开“日志”。左侧可选择 MelonLoader、管理器及已登记的 Mod 日志，查找关键词、过滤错误。日志从末尾开始显示，向上滚动时自动加载更早的内容，直到文件开头；切换日志来源时已加载的内容会保留，点击“刷新日志”重新读取。
2. 首次使用在右上角配置服务地址、模型和密钥。支持 OpenAI 兼容服务及本地服务；保存设置不会连接服务。
3. 点击输入框左下角的附件标签（如“已附带 2 份日志 + Mod 状态”）核对游戏、MelonLoader 和 Mod 状态；左侧切换到“发送给 AI 的内容”查看实际发送的文字（已隐藏个人信息），再点击“分析日志”。AI 服务和模型在“智能分析”标题旁的模型标签中设置。最多选择 3 份日志，每份从末尾 256 KB 优先选取错误与上下文，最多发送 8 KB／240 行。
4. “智能分析”显示查询、生成进度及分析结果，可以停止、重试、继续追问或导出对话。长回复、服务中断或手动停止后已收到的文字会保留，点击“继续分析”续写。切回 Mod 页面不会丢失对话。
5. 分析可以查询本游戏环境、日志、包库和外部发现的 Mod，并给出启停建议卡；核对目标和影响后点击执行。列表已改变时旧建议会失效，需要重新分析。显示顺序不能代替 MelonLoader 的实际加载优先级。

“方案”、Nexus 与 AI 都按需使用。弹出的面板可以点周围变暗的区域关闭，效果与 Esc 相同；正在部署时不会被这样关闭。对话和建议说明支持 Markdown，日志原文保持原样。AI 建议由用户点击后才执行文件操作；不自动发送 DLL、存档或整份日志。没有 AI 也能完成本地管理。

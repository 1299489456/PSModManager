# 数据、备份与重装

## 数据在哪里

点击“设置”→“数据位置”可查看当前数据目录、包库、数据库、配置、缓存和日志路径。第一次启动会引导选择位置，默认是 `%LOCALAPPDATA%\PSModManager`，也可以选择其他本地磁盘上的独立空目录。程序目录中不存用户数据；游戏 Mod 文件仍位于所选游戏目录。

数据和游戏可以在不同磁盘。Mod 操作的暂存及恢复副本保存在游戏旁的专用 `.psmm-*` 目录，数据库和包库仍留在数据目录。该目录包含中断恢复和历史撤销所需的备份，不要把它当缓存删除或移动；备份已部署状态时也要保留它。

AI / Nexus 密钥独立保存在 Windows 凭据，不写进数据文件。应用内迁移会通过原有凭据服务复制当前已记住的记录到新数据目录的命名空间；仅本次会话的密钥不会变成永久保存。凭据服务不可用时，迁移结果会提示重新输入密钥。手动复制目录或换电脑不能同时迁移 Windows 凭据，不应把含私有数据的备份公开上传。

## 在设置中迁移到其他磁盘

1. 保存或撤销模组列表中的草稿，完成当前安装操作，并关闭其他版本的管理器。
2. 打开“设置”→“数据位置”→“更换数据目录”，输入或浏览选择新的独立空目录，再点“下一步”。目标不能与当前数据目录互相包含，也不能放进游戏目录；已有个人文件不会被覆盖。
3. 核对范围后点“开始迁移”。下载和分析会停止，数据先复制和校验，成功后才切换启动位置。过程中不要关闭窗口；空间不足、文件占用或恢复记录异常时保留原目录，不切换到不完整副本。
4. 点击“重启并使用新目录”，在设置中确认实际路径。以后包库、方案、配置、历史记录、下载及导入暂存、应用日志都使用新位置。WebView 缓存会在新目录重新生成。

原目录保留为备份，确认新位置可用后可手动清理其中的大文件，但请保留 `.storage-redirect.json` 小文件，供已有快捷方式及 `nxm://` 注册命令转向新目录。默认启动位置另有一个很小的 `%LOCALAPPDATA%\PSModManager-storage.json` 记录；Windows 凭据仍由系统管理，它们不随包库搬盘。

游戏旁 `.psmm-*` 中的 Mod 操作暂存和恢复备份继续留在游戏同卷，以保留文件恢复能力，不迁入应用数据目录。有未结束的事务或待恢复标记时，先在原位置完成恢复再迁移。迁移前生成但尚未执行的部署 / 回退预览需重新生成。

## 重装或手动替换管理器

关闭管理器，保留原数据目录和自己使用的 Mod 包，完整解压新程序到另一程序目录后运行。没有管理器自动更新或 RimCrow 数据迁移。删除旧程序目录不自动清除包库、配置或游戏里的 Mod。

MelonLoader 安装在游戏目录中，和管理器程序分开。需要安装或重装时，使用“模组”页的 MelonLoader 环境入口，下载官方 0.7.3 Windows x64 包或选择该版本的官方 ZIP。重装保留现有 `Mods`、`UserData` 及加载器配置；不会自动升级到其他版本。

移除 Mod 应在“模组”页点击对应“卸载”。删除管理器程序本身不会让已安装 Mod 停用。

## 可选备份

需要保留管理器数据时，先关闭程序，再把整个数据目录**复制**到自己的备份位置，保留原目录。原始 DLL/目录/ZIP 也建议另存一份；这些副本不包含或回滚游戏存档。数据库升级会保留带版本名的单份数据库备份，它只保存数据库，不等于备份游戏或整个包库。

本版提供同一台电脑上的应用内迁移，不提供用任意备份覆盖整个工作区的一键恢复。不要把一份旧数据库单独覆盖当前包库和安装记录，或把“程序能启动”当作游戏文件已经回退。真实游戏、新电脑上的恢复和真实用户升级仍需单独核对。

处理装错 Mod 时，先使用停用或卸载；需要重新导入时使用保留的原包。手动改过游戏文件后，先点击“刷新”查看实际状态，出现外部修改/冲突时保留文件并按错误处理，不保证自动覆盖或接管。

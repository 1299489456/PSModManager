# 常见问题

| 情况 | 处理 |
|---|---|
| 管理器提示缺 WebView2 Runtime / .NET Framework | 先确认电脑具备版本说明中的运行环境；程序不会自动安装。完整解压包后重试，不用 Python/SDK 替代便携 EXE |
| 程序目录只剩一个 EXE、helper 不可用或资源缺失 | 重新完整解压同一便携 ZIP，保留 `_internal` 和 `PSModManager.WorkerHost.exe`，勿混用不同目录的文件 |
| 没有自动找到 Steam 游戏 | 点击“选择游戏安装”，手动选择游戏根目录或 Steam 目录；多个安装可自行切换 |
| 无法选择安装目录 | 选择含 `Probably Stolen.exe` 的游戏根目录，不是 `Mods` 子目录；确认目录和可执行文件可以读取，无需游戏指纹 |
| MelonLoader 未安装或安装不完整 | 在“模组”页点击下载安装 MelonLoader，或在“环境与安装”中选择“从本地 ZIP 安装”。本地 ZIP 仅支持官方 0.7.3 Windows x64 原包；重装保留 `Mods`、`UserData` 和配置 |
| MelonLoader 提示缺 .NET / VC++ 环境 | 在环境详情中打开官方链接，安装 .NET 6 x64 Core 或 Desktop Runtime、VC++ x64 运行库后重新检测。管理器自带的 helper 运行时不等于游戏所需运行时 |
| MelonLoader 显示已停用 | 关闭游戏，检查游戏目录 `UserData/Loader.cfg` 的 `[loader] disable`，需要加载 Mod 时设为 `false`；同时移除自己设置的 `--no-mods` 游戏启动参数，再重新检测 |
| 文件被占用 / 游戏正在运行 | 正常关闭游戏和占用目标文件的编辑器，回到管理器刷新后重试；管理器不强制结束未知进程 |
| 权限不足 | 确认当前用户对程序数据目录和游戏 Mod 目标有写权限，优先使用自己可写的位置；管理器不自动提权或改系统权限 |
| 空间不足 | 清理自己不需要的文件或选择有空间的位置后重试，不把失败当成功 |
| ZIP 无法入库 | 使用普通 ZIP；检查 4000 文件、64 MiB 单文件/ZIP、256 MiB 展开总量限制及提示；不支持加密、分卷、嵌套包、RAR/7z 或安装脚本 |
| MelonLoader 本地 ZIP 不被接受 | 使用环境详情中的专用安装入口，重新下载官方 0.7.3 Windows x64 ZIP；其他版本、x86 包或重新打包的 ZIP 不适用 |
| 文件已存在、归属未知或外部修改 | 保留你改过的文件，查看提示和实际路径；刷新只读取状态，不会擅自覆盖。不能保证任何外改都能自动恢复 |
| 安装成功但游戏仍报错 | 文件安装和玩法兼容是两件事；核对 Mod 所需游戏/加载器/依赖版本，先停用对应 Mod，再按需要排查 |
| AI 不可用 | 检查自己填写的服务、模型和 key；只有主动测试/发送才联系服务。可继续本地安装/启停/卸载，无需等待 AI |
| 智能分析提示模型长度已用完或达到本次预算 | 已收到的内容会保留，点击“继续分析”续写；“重试原请求”会重新发起原问题，不等于继续。旧版“回复超过本次显示范围”问题已按接收/传输/显示/模型限额分别修复 |
| 智能分析建议已失效 | Mod 列表或版本已改变，刷新后重新分析；旧建议不会静默覆盖当前列表 |
| 拖入新版后仍看到旧版 | 先加入包库，再打开“安装 / 更新到游戏…”确认替换；单纯添加到包库不会更改游戏。旧版本继续留在包库供降级或旧方案使用 |
| 分享 ZIP 超过 64 MiB | 在“方案”页点“导入”选择整合包；整合包最多 4000 文件、1 GiB，不走普通 Mod ZIP 的上限 |
| JSON 方案缺少版本 | JSON 只含清单；请让分享者导出包含 Mod 的完整 ZIP，或自行导入清单指定版本 |
| Nexus 无法直接下载 | 普通账户需在官网生成该文件的 nxm:// 授权链接；链接须属于当前 API Key 账户且未过期。Premium 才能不附此链接直接下载 |
| Nexus 列表找不到某个 Mod | 当前入口展示最近/热门列表，筛选只作用于已加载列表；完整目录和全站搜索使用“浏览官网” |
| 打开开关后游戏没有变化 | 先点“待保存”篮子里的“保存”，或使用“保存并启动”。未保存时只修改草稿 |
| 保存提示列表已改变 | 游戏目录或包库在读取后发生了变化；保留需要的文件，再放弃草稿并重新读取。不会用旧草稿静默覆盖新状态 |
| 保存中断或提示有未完成操作 | 重新打开管理器，等待恢复结果。保留数据目录和游戏旁的 `.psmm-*` 目录；若提示文件被外部修改，先保留这些文件，不要反复强行覆盖 |
| 分析日志按钮不可用 | 先选有内容的日志；尚未生成或为空时先运行游戏产生日志再刷新。未配置 AI 时点击分析会展开服务设置并说明原因 |
| AI 找不到较早的报错 | 阅读窗口与发送资料不同；发送资料仅扫描每份日志末尾 256 KB。可选择对应历史日志，或把需要的原文复制到问题中明确提供 |

在“应用信息”中查看数据目录与日志文件；反馈问题时说明按钮、错误文字和自己已做的操作。分享日志前检查个人路径和敏感内容，别发送密钥、完整存档或不需要的 DLL。

当前 EXE 未作发布签名。Windows 出现来源提示时，先核对提供者和 ZIP 的 SHA256；不要通过禁用系统防护来掩盖来源或文件异常。包内 `SHA256SUMS.txt` 校验各文件，ZIP 本身的摘要随本地分发清单提供。

# 普通 Mod 安装与管理

版本：2.0；PS-03-07 普通 Mod 管理已接通，内部复用旧 planner/executor；可选配置保存按第 7 节独立接通。

## 1. 安装

1. 用户选择游戏和要安装的 DLL、目录或 ZIP。
2. 显示包名、版本和安装位置；详细文件列表按需展开。
3. 用户点击“安装”，后端做基本目录、解压与目标检查，然后复制/替换文件。
4. 显示实际结果；失败说明哪个动作出错，并提供重试或重新选择入口。

不要求先创建/保存方案、审核兼容图、单独批准计划、原生再确认、运行游戏或对账恢复历史。AI 推荐的 Mod 被用户选择安装后走同一动作。

## 2. 启用、停用、卸载

- 启用：把该 Mod 文件放回加载器可读取的位置。
- 停用：移到扫描树外或移除部署副本，包源保留便于再次启用；列表顺序不声称游戏加载顺序。
- 卸载：删除用户选择的 Mod 部署文件，更新实际安装状态。
- 用户主动清空 Mod 目录时，可以一次普通确认后清理所显示范围；不扩大到游戏核心文件、正式存档或系统运行时。

已有文件、共享文件或用户编辑影响所选动作时，给直接说明和明确的保留/覆盖选择，不升级成长期恢复问题或审批记录。简单安装记录帮助定位文件即可，不新增多层 owner/代次证明。

## 3. 基本检查与普通错误

目标仅限支持的 Mod 目录（当前 Mods、Plugins、UserLibs）。拒绝 ZIP 路径越界，不执行安装脚本，不递归操作指向范围外的链接。

路径无效、权限不足、文件占用、空间不足、坏 ZIP、来源丢失时，停止失败的动作并显示原因。不要强制杀未知进程、自动提升系统权限或改加载器；提示关闭游戏或重试即可。操作完成前不显示成功，多文件部分完成也说明实际情况。

兼容提示可以帮助用户，不因不确定风险或未做玩法验证就禁止普通安装。支持的安装范围与真正的文件错误分开。

## 4. 备份与重装

备份是可选便利功能：例如覆盖前的一份文件副本或最近一次安装前备份。能恢复就恢复，不能恢复则说明并允许用户重新安装/删除 Mod。

不承诺多代次无损回滚、硬件断电/磁盘故障恢复、任意外改自动修复。不要求每次操作创建完整目录指纹、HMAC 批准、持久恢复问题台账或运行验证记录。

## 5. 复用当前实现

现有 planner、executor、路径检查、journal 和备份代码可以内部复用，避免另起一套文件操作。旧能力不继续扩写为首版必验，也不把内部状态要求交给用户操作。

`mod.action` 在后端固定安装和版本，保留其他已启用 Mod，为此次普通动作内部准备计划并调用同一个 executor，不经过用户方案或确认弹窗。启用从包库恢复文件，停用移除部署副本并保留安装成员，卸载移除成员和该 Mod 独占副本；相同内容共享文件仍有其他启用者时保留。提交和恢复同时发布内部安装成员，停用后卸载的无文件动作也持久保存。

缺少的扫描根和目标父目录由 executor 在现有安装锁及固定目录句柄下创建；后续失败可留下空目录，不删除原有目录。只支持 Mods、Plugins、UserLibs，未知占位或用户外改直接反馈并保留，不自动覆盖。包库仍保留用于重装；卸载不是删除包源。

兼容图在普通动作中作为提示依据，不禁止未做玩法验证的安装；真实目标冲突、坏包、链接越界、权限、占用、空间和未完成文件操作仍会停止并显示普通错误。现有恢复阻断保留，不假装被界面隐藏后不存在。原 `plan.apply` 等可选高级入口继续校验原批准，未在本卡重写历史恢复流程。

## 6. 针对性验证

验证正常安装、再次安装、启用、停用、卸载、坏 ZIP/越界路径及常见文件错误，并核对实际文件和列表状态。普通桌面入口需要实际消费者验证；构建成功不替代功能测试。

连续导入和刷新不受已完成操作累计数量限制：后台按固定容量回收无人订阅的已结束任务及旧的已完成导入预览，保留正在处理的动作。临时记录过期时重新读取实际列表或选择来源，不要求用户处理审核或恢复台账。保留规则见 [数据契约](03-data-contracts.md)。

可选最近备份单独测能否恢复。旧强杀矩阵、多代回退、安装 lease/进程身份极端竞态和断电专项保留历史结果，不作为当前首版全部必经条件。当前 CASE 与旧用例区别见 [矩阵](07-validation-matrix.md)。

## 7. 可选配置保存

PS-03-05 仅支持 `UserData/PSWallpaper.cfg` 的三个已有字段，目标由后端固定，不扩大普通包部署目录。用户在“配置”弹窗保存一次即可，既有 Profile 的 `config_overrides` 仍不用于混合 DLL/配置部署。

读取和保存保留未知字段、注释、编码、换行及未修改值；不能可靠解析则只读。保存先比较读取时的文件摘要，文件被外部修改时不覆盖。游戏运行、文件占用和只读/权限错误直接说明原因。可选原文件备份保存在管理器私有数据目录，不写正式存档或其他 Mod 配置。

保存使用现有安装守卫及固定文件的独占写句柄，异常时尽力从内存恢复该文件；不建立多代历史或新 journal。硬件故障、进程在写入中被强杀及游戏内生效不在本卡承诺范围；需要时使用原文件备份或外部编辑器。

## 8. 可选启动

PS-03-06 顶栏按钮直接调用固定安装的启动服务，不需要先做方案或玩法验证。沿用部署/回滚共用的安装锁、实际进程和未完成文件操作检查；只创建所选安装的 EXE，工作目录固定，不拼 shell。先核对新进程的实际映像再恢复主线程，检查失败时只清理本次创建的未运行子进程。

已在运行时不重复启动、不结束外部游戏。成功状态只说明进程已发起，退出后显示实际退出码；无法启动显示原因，可刷新或重试。关闭管理器不停止游戏，不建立游戏运行历史或强制日志会话，不把这些能力前置到安装/启停。

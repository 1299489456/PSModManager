## 实现步骤

1. 按06的5000组件基准记录环境、搜索p95、反馈与取消延迟，不混入首次强hash总耗时。
2. 验证键盘焦点、多选、DPI、长中文路径、错误恢复和窗口重开。
3. 只针对测得瓶颈做范围内优化，保留所有权/事务/证据不变量。
4. 运行跨模块既有回归和必要静态/构建检查，列性能未达项。

## 验收标准

1. 基准达标或具体失败阻止相关验收，不能缩样本凑数。
2. 桌面无阻塞扫描/未关闭watcher/取消后后台遗留。
3. 键盘和状态非纯颜色可用，125/150/200%DPI主要流程无截断阻断。

## 验收标准

1. 缺硬依赖、目标冲突、空间不足、旧批准、指纹漂移均不进入写入。
2. 无变化计划明确no-op，不伪造新部署；相同idempotency_key不重复。
3. 预览完整展示文件/配置/重启/备份影响，非模型自报审批。

## 实现步骤

1. 重新核对 RimCrow 提交/工作区与本项目已有文件，记录实际开发工具版本、锁文件、子模块状态。
2. 从固定提交取得源码并按白名单导入本项目；不带 .git/.codegraph、原用户数据、构建产物，不覆盖现有 docs。
3. 登记保留/改写/移除模块清单与第三方来源；保留版权声明，记录旧扫描和初始化副作用；不运行旧应用。
4. 盘点原测试可执行性与缺失依赖，原历史测试仅为参考。

## 验收标准

1. 源仓库内容和 Git 状态保持不变；本项目有可追溯提交、文件清单和排除项。
2. 导入未覆盖本次规划和原报告，未复制游戏/模组/凭据/用户数据库。
3. 依赖缺口、旧测试未运行项明确列出；没有隐式安装、提交或初始化远程仓库。

## 实现步骤

1. 选定PyInstaller构建路径，包含前端dist、规则/资源、helper及其运行时策略，记录锁文件/工具版本。
2. 使用独立产品名称和数据根；禁用原更新渠道及用户数据迁移；便携程序数据默认LocalAppData。
3. helper优先独立自包含产物，实际可复现和体积由本任务证明；WebView2缺失明确提示，不静默安装。
4. 产物排除真实游戏/DLL/存档/key/开发数据库，生成hash与依赖材料清单。

## 验收标准

1. 无开发环境机器可按明确前置条件启动，运行时依赖列表完整。
2. 源码包/发布包不含真实资源和秘密，程序文件与用户数据分开。
3. 构建重复有可解释差异；不能仅一条build成功即宣称可交付。

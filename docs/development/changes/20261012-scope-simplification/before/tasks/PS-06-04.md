## 实现步骤

1. 确定独立发布源/真实性验证与签名材料，不复用RimCrow更新地址。
2. 先缓存校验，等待管理器退出和无部署事务再更新，禁止更新时遗弃恢复状态。
3. 数据库迁移备份、程序版本与数据版本协调，失败能恢复旧可运行组合。
4. 明确用户选择更新范围与发布操作权限，不因开发任务自动上线服务。

## 验收标准

1. 截断下载/签名失败/进程占用/升级崩溃不会覆盖可用版本。
2. 旧schema/新schema不兼容时拒绝旧版本写入，并提供备份恢复。
3. 渠道归属独立，停止网络仍可手动升级和本地管理。

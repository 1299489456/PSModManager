## 实现步骤

1. 从已提交历史生成新恢复计划，不直接覆盖当前目录或仅回退数据库。
2. 当前必须匹配after哈希；外部改动先保全到冲突备份，拒绝破坏性自动还原。
3. 支持共享owner退出、未知文件保留、原本不存在目标的回滚和已损坏备份检测。
4. 历史与未完成事务保留策略受引用保护，明确手动清理边界。

## 验收标准

1. 用户外改文件无损保全；回滚失败保留recovery_required，不能显示已恢复。
2. 新增文件只有仍匹配本事务产物时移除，配置/可变数据不因停用删掉。
3. 回滚可中断再恢复；历史代次与实际文件一致。

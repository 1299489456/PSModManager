## 实现步骤

1. 按版本/配置扫描Mods/Plugins/UserLibs允许范围及manifest子目录，不调用旧RimCrow扫描。
2. 记录文件身份、size/hash/mtime、组件元数据和扫描generation，缓存按解析版本失效。
3. 实现取消、错误隔离、complete/partial/failed状态；仅完整权威扫描可以标missing。
4. 实现同名程序集版本候选计算；磁盘在扫描期间变化则重试有界或标漂移。

## 验收标准

1. 扫描前后游戏树内容/名称保持不变；文件发现和实际加载预测分开。
2. 中文/空格/%/大小写路径正确；权限/离线/取消不删历史索引和用户标签。
3. 过期扫描不能覆盖新代次；缓存仅优化读取，部署前仍强哈希。

## 实现步骤

1. 实现05列出的只读工具，返回结构化摘要/证据ID/来源与覆盖范围。
2. 每次执行重新校验session allowlist、安装范围、schema、限额和取消状态。
3. 拒绝未注册/已注册但未授权工具、任意路径参数、跨安装访问和伪造evidence ID。
4. 为日志/模组说明/工具结果中的提示注入建立回归，不允许文字授予能力。

## 验收标准

1. 模型强行返回隐藏工具名仍被后端拒绝，不依赖schema隐藏。
2. get_supported_config_view只读已适配脱敏字段；管理器备注不冒充游戏存档。
3. 所有工具有界输出、超时与证据来源，权限失败可解释且不泄露路径。

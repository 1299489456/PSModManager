1. 实现轮次/工具/总时限、规范参数重复检测、有限网络重试和令牌预算。
2. 取消停止流和调度、释放资源；事务applying期间按04处理取消，不能遗弃journal。
3. 部署后只在授权范围启动或等待用户运行，再将分层结果回传会话。
4. 429/断网/未知模型/预算耗尽保留证据并结束，离线管理不受影响。

## 验收标准

1. 相同失败不无限循环修复/启动；任务恰好一个终态。
2. 超时/取消后无存活worker或仍写游戏的隐藏任务。
3. 无新运行证据时输出待验证，成本未知不编造精确金额。

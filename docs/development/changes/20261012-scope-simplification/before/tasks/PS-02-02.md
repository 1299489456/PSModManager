## 实现步骤

1. 实现source_handle、导入清单预览、暂存校验与import_commit；扫描恶意文件仍走受限worker。
2. 只支持DLL/目录/ZIP，拒绝脚本安装及不支持压缩格式并说明原因。
3. 规范化Windows相对路径，检查解包前后路径、链接、重解析点、ADS、保留名与大小写冲突。
4. 限制文件数/展开大小/单文件/压缩比和输出，完成后提交私有库索引；失败仅清理自身暂存。

## 验收标准

1. 路径穿越、绝对路径、ZIP bomb、软硬链接/联接不能写出暂存根或游戏目录。
2. 导入预览精确展示目标角色/未知归属，不自动启用/部署。
3. 中文/空格/%合法文件名不损坏；重复导入幂等，磁盘不足无半包。

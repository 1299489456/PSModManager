## 实现步骤

1. 真实桌面使用合成provider验证内容包、遮蔽、自停用、旧文案、恢复等场景。
2. 加入恶意日志、伪批准、陈旧计划、断网、用户取消并检查安全降级。
3. 获得具体provider/发送范围授权后做最小脱敏真实会话，不要求上传真实DLL/存档。
4. 记录模型/协议/预算、计划批准与新运行验证边界，汇总G4。

## 验收标准

1. UI→runtime→工具→提案→计划→合成部署→验证链真实联通。
2. 真实provider仅验证模型接入和证据使用，不替代真实游戏玩法验收。
3. 缺真实provider证据保持ai-live未验证/G4未通过；本地MVP仍可独立使用。

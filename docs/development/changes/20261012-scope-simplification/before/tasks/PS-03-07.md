## 实现步骤

1. 接通差异/批准/应用/取消/恢复/历史/回滚，不通过前端列表修改模拟部署。
2. 真实WebView+合成安装完成双Profile切换、混合配置、崩溃恢复和漂移冲突闭环。
3. 实机前确认具体授权、存档位置/可丢弃测试存档、备份和Steam Cloud边界；无法确认不启动实验。
4. 获授权后执行限定组合部署→启动→新日志验证→回滚并比较原部署，汇总G3。

## 验收标准

1. 离线能完成所有基础管理；未授权不会写真实目录或启动游戏。
2. UI只按真实后端结果显示部署/验证；恢复页能继续处理失败而非只吐错误。
3. 真实游戏和回滚有新证据，玩法/云隔离未知明确保留；缺实机G3不得PASS。

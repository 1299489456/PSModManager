## 实现步骤

1. 定义严格PlanProposal，后端把组件ID和操作意图转为ActionPlan，不信模型提供的目标路径/hash。
2. 卡片展示证据/影响/备份/验证边界并引用普通计划预览与批准。
3. 执行仍调用deployment服务，绑定profile revision/generation/plan_hash，重复点击幂等。
4. 陈旧/已撤销批准拒绝；不继承旧MOD_STATE直接改列表宣布修复。

## 验收标准

1. AI与手工同操作产生相同受控计划与权限检查。
2. 模型伪批准、越界动作、额外字段和陈旧状态无法执行。
3. 卡片显示真实transaction/verification状态，未运行不得显示已修复。

## 实现步骤

1. 分别计算包依赖/API能力、文件所有权冲突、运行交互提示，不合并为万能排序。
2. 对已确认硬依赖生成启用闭包预览；禁用影响展示引用链并让用户选择。
3. 程序集遮蔽、同目标不同hash、框架内内容ID碰撞都有证据与指纹范围。
4. 环与未知关系给出解释，不自动删弱边冒充修复；拖动显示顺序不改变loader规则。

## 验收标准

1. 硬依赖缺失和写冲突可阻断计划，软/潜在风险不一律阻断。
2. 报告完整影响集合，不无提示连带删除或启用。
3. 未知Loader/来源推断不作确定兼容结论；不同框架同BundleId不误报。

## 实现步骤

1. 解析Steam库/appmanifest与手选目录，验证EXE/Data/GameAssembly/global-metadata/Loader，不按目录名猜安装。
2. 记录Demo/正式版/未知渠道、buildid、raw游戏版本和Loader版本；区分历史日志观察与当前文件。
3. 解析安装文件身份和路径别名，data root冲突拒绝，强指纹后台有界读取。
4. 提供安装选择API与最小页面，拒绝扫描未认可目录。

## 验收标准

1. Demo不混正式版AppID；0.46D等原始版本无损保留。
2. 路径别名不重复登记；损坏/不完整安装有具体缺失项。
3. 读取不写游戏/Steam manifest；部分指纹不被标完整可部署。

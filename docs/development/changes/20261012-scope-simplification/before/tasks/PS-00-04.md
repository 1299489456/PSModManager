## 实现步骤

1. 实现显式 dispatch 白名单、schema参数校验、错误封装，不反射开放所有public方法。
2. 实现 task_id/sequence/快照/唯一终态和取消协议，UI重连可续接。
3. 建立真实 pywebview→JS→Python→JS harness，用隔离数据根和自制无副作用命令。
4. 以真实桥接证明未知命令拒绝、非法参数拒绝、事件排序与取消；不使用浏览器mock冒充。

## 验收标准

1. 页面只能调用白名单，外部页面没有js_api；不监听业务HTTP端口。
2. 旧任务取消不能作用新任务；重复/乱序事件不重复完成或覆盖新状态。
3. 真实WebView harness有可重复入口和退出码；环境不足保持BLOCKED。

## 验证内容与命令

- tests/unit/test_api_policy.py：命令/参数拒绝与输出脱敏。

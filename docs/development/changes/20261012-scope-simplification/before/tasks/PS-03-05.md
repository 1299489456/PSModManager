## 实现步骤

1. 为样本中经验证字段建立adapter/schema；识别共享/私有/业务进度归属。
2. 保留注释、未知字段、编码/BOM/行尾；无法保真解析只读降级。
3. 配置修改生成同一ActionPlan，整文件before哈希与键级差异同时绑定。
4. 禁止运行中写配置，备份按原字节，导出脱敏；Profile覆盖不吞掉游戏回写。

## 验收标准

1. 中文裸表名/特殊CFG不被错误重写为标准TOML；未知配置不自动纠正。
2. 允许字段变更其余字节按adapter保真约束不变，进度标记不丢失。
3. 外部回写/敏感值/错误字段类型/重复键歧义均得到安全拒绝或明确降级。

## 实现步骤

1. 按真实安装身份建立OS独占lease，PID+启动时间验证owner；多实例冲突可解释。
2. 目标白名单和祖先身份校验，拒绝reparse/ADS/保留名/歧义路径，并在实际写前再检。
3. 识别指定EXE真实进程而非只按名字；访问受限/不确定时禁止写入，禁止强杀真实游戏。
4. 提供未来executor每一步调用的guard；未完成事务可读不可写/不可经管理器启动。

## 验收标准

1. 路径替换/联接逃逸、相似前缀安装、双进程争锁不会越权写。
2. 游戏运行或进程状态无法确认时拒绝apply；只有准备计划可进行。
3. owner崩溃自动释锁，旧PID重用不误判；不删除不明锁文件强抢。

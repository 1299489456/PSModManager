## 实现步骤

1. 编写首次接管、导入/启停、配置、恢复、诊断/AI发送范围和升级/备份步骤。
2. 按实际产物登记来源/许可/素材/运行时，排除未确认可分发内容；保留RimCrow版权说明。
3. 消费PS-05-03的CASE-048升级/回退证据，汇总G0-G5证据和已知限制；该卡承担材料复核而非重做产品验收。首版明确支持范围与未实现M6，不生成虚假的通过清单。
4. 准备本地可交付包/校验和/文档；发布、签名凭据、上传与push需另有明确指令，本任务不自动发布。

## 验收标准

1. 用户按文档可完成主要流程并在失败时找到恢复入口；文档与打包行为一致。
2. 每个首版需求对应实现和验证证据；未验证/失败无隐藏。
3. 本地产物齐备且G5依据明确，外部发布状态仍独立。

## 验证内容与命令

- release profile：文档步骤复核、产物内容/哈希/许可清单和阶段门证据复核。

需要的 Profile：release。命令在项目根目录执行；所列产品文件/测试/harness为本任务或前置任务交付物，当前规划阶段尚不可运行。缺工具、依赖或必要资源时记录BLOCKED/NOT_RUN，不自动安装、不用空测试替代。

```powershell
pwsh -NoProfile -File scripts/verify.ps1 -Task PS-05-04 -Profile release
```

runner由PS-00-05实现，必须精确映射本卡测试和必要CASE；不支持的Profile不得返回成功。

常规实现/验证仅写项目、独立测试数据根和可枚举临时目录。已有且适用的授权持续有效；真实目录写入/启动、外部联网、依赖安装和发布若不在已有授权内，则先取得缺失范围。禁止将实机缺口写成PASS。M6未明确指定不实施。

本任务不授权提交、推送、发布、修改加载器/系统运行时或正式存档；分析和合成实现可继续，不能因此扩大任务范围。用户明确追加授权时记录其范围即可，无须逐文件重复确认。

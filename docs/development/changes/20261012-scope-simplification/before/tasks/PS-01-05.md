## 实现步骤

1. 实现文本增量decoder、残行、文件identity/epoch/offset、迟到/轮转/截断处理。
2. 聚合MelonLoader与选定UserData日志，解析阶段/时间和多行堆栈，Latest/归档去重。
3. 按会话注册 evidence ID+原片段哈希，限制根、文件数和读取窗口。
4. 接统一任务事件；UI关闭重开不重复监视，程序退出释放句柄。

## 验收标准

1. 中文跨块和半行不丢失/重复；日志替换后原evidence不指向新文本。
2. 历史会话不会绑定到新部署；不能确定PID/会话时保持unknown。
3. 大日志分页与监视不阻塞UI，出错可恢复且无全文件上传。

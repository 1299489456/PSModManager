## 2. 产品定位与分期

首版面向 Windows x64、本地安装、Probably Stolen Demo 的已核验加载器组合。正式版和其他加载器版本可以登记为未知兼容，不直接套用 Demo 验收。核心承诺：解释安装内容，可靠切换组合，保护用户数据，展示本次运行证据。

- M0：独立开发基线；可启动新产品，不触碰 RimCrow 数据。
- M1：只读诊断版；用户能扫描、识别模组与内容包、查看加载差异和问题来源。
- M2：离线组合编辑版；能安全导入私有库、编辑 Profile、预览变化，尚不写游戏目录。
- M3：离线管理 MVP；能预览、部署、启动、验证、回滚。
- M4：AI 增强版；AI 通过证据工具提出同一套 ActionPlan。
- M5：可交付 Windows 便携版；完成安装态、升级/恢复和使用文档验收。
- M6：延后能力；独立授权后才开展，不阻塞首版。

## 4. 首版不做

不移植 RimWorld 工坊、DLC、贴图压缩、XML 翻译、社区排序规则；不做通用游戏平台、模组商城、任意 Harmony 排序、DLL 热替换、任意 shell Agent、存档自动迁移、加载器自动升级。安装第三方组件由后续明确任务处理。

兼容规则可提出建议，但不能偷偷改 DLL 文件名排序。停用库放在游戏扫描树外；不以 `Mods/disabled` 作为可靠隔离。不将 `-savedatafolder` 照搬给本游戏。

## 5. 开发资源边界

常规任务使用仓库内自制 fixture 与临时安装树，真实游戏与 RimCrow 是只读参考。真实游戏启动会写日志/配置，属于单独实机验证范围；不要把“仅读取游戏目录”的授权扩大成启动许可。

用户已在本会话授权分析真实目录，但未授权更改部署、存档、云同步、运行时或加载器。任务计划中的实机步骤必须在执行时具备具体资源授权；没有授权可完成合成验证，不能把阶段门标 PASS。禁止上传真实 DLL、存档、完整日志或凭据到公开仓库/AI。

# 可选 AI 能力与验证结果

PSModManager 的基础流程是本地添加、安装、启用、停用和卸载。AI 为可选辅助，不要求创建方案、批准计划、启动游戏或取得运行日志后才能管理 Mod。

## 当前实际入口

在“AI（可选）”页填写 OpenAI 兼容服务地址及模型，按需提供 key；主动测试/发送才联系服务。key 使用现有独立凭据或本次会话内存，普通 Mod 页不调用 AI，也不读取或迁移 RimCrow 凭据。

普通提问只发送当前问题、自选文本及有界问答。勾选查询后，模型可查询当前已选安装、包库、已安装状态、一个手选日志片段和三个已支持的 PSWallpaper 配置字段。完整 DLL、包二进制、存档和未选日志不自动发送。

查询结果可以用于解释日志和选择已登记包。模型的 `suggest_mod_action` 只生成安装/启用/停用建议卡，名称和版本来自包库；用户点击按钮才复用普通 `mod.action` 服务及文件状态刷新。卸载使用普通管理按钮。外部文字中的命令、脚本或“用户已批准”不赋予文件操作能力，AI 不自动安装、删除或启动游戏。

请求限额、取消和失败提示复用 PS-04-04：默认整次60秒、累计16000字节文本、最多4次 HTTP、3批/12次工具，无自动网络重试。失败可手动重试，修改范围或输入后旧重试失效；取消停止后续调用，不产生可点的半成品建议。费用未知不估算金额。文件操作完成只说明安装/启停等文件结果，不证明玩法兼容或游戏问题已修复。

## PS-04-05 的验证范围

本轮使用 owned 合成安装、隔离 data root 和真实 loopback HTTP/SSE。API、Gateway、查询服务、建议解析、普通执行器和实际 WebView 均使用产品入口；合成响应只决定模型将返回哪种文本/工具调用。

合成API闭环当前5项通过，涵盖所选日志→查询/搜索→建议→用户调用普通安装及启停/卸载、夹带指令及无效选择、查询后取消、无配置/离线/关闭AI后本地添加与普通动作，以及联网入口使用真实封闭API封套的本地检查。真实联网检查为1 SKIP；新增原生类型缓存回归1项和相关守卫补测15项均通过。首轮合成路线中的新测试计数API错误已保留并作窄修正，不把分轮结果写成单次全通过。

当前实际WebView完整路线 **1 PASS、exit 0**：9项行为检查、3次目录添加、13次普通Mod动作、7次localhost HTTP/SSE和5张截图。进程自然退出，所有工作线程、订阅和进程残留均为0；provider请求体的发送范围与脱敏断言也全部执行。结果见 [当前记录](evidence/PS-04-05/20261013T051122Z-clr-exit-fix/summary.json) 和 [修复报告](evidence/PS-04-05/20261013T051122Z-clr-exit-fix/report.md)。

此前 `desktop-03` 的360秒CLR卸载超时及 [原报告](evidence/PS-04-05/20261013T030746Z-ai-workbench/report.md) 保留。问题来自原生路径/进程检查每次重建ctypes ABI类型，指针类型缓存持续累积，放大卸载时的Python垃圾回收成本。现在复用固定结构体，原字段、文件/进程保护与普通动作规则未改变；没有跳过CLR卸载、强制退出或更新依赖。25批真实原生调用的原版缓存新增6505，修复后首次初始化新增2，后续24批均不增长。

合成接线通过不能证明具体真实模型的解释质量、推荐正确性、协议兼容或费用。ai-live 本轮 NOT_RUN：没有具体 provider/模型/发送范围授权，未联系外部服务；默认禁用检查得到1 SKIP，不计入联网通过。真实游戏、用户实际 Mod 个案、正式存档、可信指针/人工体验/系统DPI及发布均未验证。

## 可选的真实供应商直接入口

`tests/acceptance/test_ai_provider.py` 是已有服务的最小联网消费者。取得具体服务、模型和发送范围授权后，在当前测试进程显式设置 `PSMM_AI_LIVE_ENABLE=1`、`PSMM_AI_LIVE_URL`、`PSMM_AI_LIVE_MODEL`，按需通过 `PSMM_AI_LIVE_KEY` 提供 key；未设置启用参数时直接跳过，不读取用户现有 AI 配置或密钥。key 不放到命令行或报告。

只发送固定合成问题：“请用一句中文说明：Mod 文件安装完成，不代表游戏玩法兼容。只解释，不请求或修改任何文件。”不提供工具、游戏选择、日志、包、DLL、存档或历史。该检查至多一次服务请求、30秒、2000字节回复，不自动重试；保存不含密钥的结果，费用为 UNKNOWN。这个联网分支本轮没有运行，后续须按实际结果记录，不能从脚本存在推导通过。

使用本卡 evidence 下的 `--basetemp` 和隔离环境，`PSMM_VERIFY_PROFILE=ai-live`；当前 runner 没有本卡映射，直接入口为：

```powershell
./.venv/Scripts/python.exe -B -m pytest tests/acceptance/test_ai_provider.py -q -rs --basetemp "$taskRun/ai-live-tmp" --junitxml "$taskRun/ai-live.xml"
```

未测真实供应商不阻断已验证的本地管理和合成AI接线，也不产生 G4 或人工放行步骤。

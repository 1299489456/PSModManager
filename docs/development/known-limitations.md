# 当前已知限制

当前首版面向 Probably Stolen 的 Mod 管理。安装、启停、卸载、方案分享与确认后版本替换已接通，目标为 `Mods`、`Plugins`、`UserLibs`；提供用户主动安装官方 MelonLoader 0.7.3 Windows x64 和 Nexus 在线获取。没有其他游戏适配、自动更新、存档管理或任意 shell AI。

- 仅 DLL、目录、ZIP；导入最多 4000 个文件，工作区保存最多 4000 个文件操作，保留 64 MiB 单文件/ZIP、256 MiB 展开总量限制。不支持 RAR/7z、加密、分卷、嵌套包和安装脚本。
- PSMM 分享整合包使用独立清单与文件校验，最多 4000 个文件、1 GiB 内容；普通 Mod ZIP 的 64 MiB 限制不套用到整合包。只包含选定版本与附件，不包含游戏、存档或凭据。仅清单导入不能凭空补齐缺少的 Mod。
- 新旧版本优先按 DLL 内嵌身份识别；只有相同目标文件等弱线索时需用户确认关联。原文件名中的版本是辅助信息，不执行 DLL 猜测身份。替换可清理旧版独有的已知文件，未知或外部修改文件仍会阻止覆盖。
- Nexus 当前是个人 Key 接入：提供全目录浏览和最近/热门列表，下载仍受账户权限限制。Premium 可直接下载；普通账户在官网 Manual download 后选择已下载 ZIP/DLL 导入。仅当官网实际提供管理器下载入口时使用 NXM 接收；注册协议不会使官网按钮出现。下载只接 ZIP/DLL，最大 64 MiB；公开分发前的应用注册条件见[使用说明](../user/sharing-updates-online.md)。
- 主列表按管理器已知包、根 DLL 及同名资源目录分组，不通过执行 DLL 猜测关联。无法确定归属的散落资源不冒充独立 Mod；特殊布局可能需要作为完整目录导入。界面不提供拖动排序，加载顺序由 MelonLoader 决定。
- 日志阅读按 32 KB 分页；每次 AI 分析最多 3 份日志，每份扫描末尾 256 KB、提取最多 8 KB／240 行，界面标明截断。尚未核实 Probably Stolen 的独立 `Player.log` 路径，不套用 RimWorld 路径。
- 安装成功表示文件操作完成，不保证游戏内注册、依赖版本、玩法或所有真实 Mod 兼容。当前合成样本不能代表所有实际包。
- GitHub Release 公开包只内置 Cpp2IL 和配套插件的离线恢复资源，不含 Unity 运行库；首次生成或游戏更新后，MelonLoader 仍需联网下载 Unity 依赖，网络不可达时可能生成失败。本地完整包与公开包的资源范围不同。
- 普通 Mod 操作按整次动作记录恢复状态，不再逐文件强制刷盘；正常失败或取消会尝试恢复，中断后重开处理整批记录。突然断电仍可能造成文件不完整，需要核对并从保留包库重装。旧严格部署和历史入口保留原记录兼容。
- 真实外改、未知归属、占用、权限和空间错误会阻止相应动作并提示；不保证自动覆盖、接管、任意损坏无损恢复或多代灾难回退。手动删除文件后，管理记录不一定自动修好。
- 数据与程序目录分开；支持首次选择位置及设置中的同机目录迁移，先复制校验再切换，原目录保留备份；游戏旁同卷恢复区和 Windows 凭据不作为普通文件搬移。没有任意备份一键覆盖恢复或跨电脑迁移；真实游戏和真实用户数据未用于本轮测试。
- 当前实际检查使用开发宿主的同用户非提升 token（Medium、管理员组 deny-only）；干净机器、独立标准账户和物理缺运行时机器未测。隐藏开发 PATH 不等于没有开发环境。
- EXE 未作发布签名；WebView2 与 .NET Framework 由目标系统提供，管理器不静默安装。实际最低系统组合需在目标环境再核对。
- MelonLoader 安装仅支持官方 0.7.3 Windows x64 原包，以该发布包摘要确认 ZIP。安装与重装保留 `Mods`、`UserData` 和配置；不会自动安装 .NET / VC++ 系统运行库或启动游戏。普通 Mod 动作不等待此项，但加载 Mod 需要相应运行环境可用。安装与环境检测不等于游戏实际加载成功。
- 智能分析已用 localhost 模型验证长回复、多轮分页和预算收束、工具前分析保留、取消、人工继续、环境查询和确认启停；已用真实 deepseek-flash 完成合成日志→查询→分析→建议→合成环境确认停用→追问核对。真实游戏修复效果及其他模型未测。一次请求默认 180 秒、256 KiB 接收内容，查询有限但预留最终分析，达到接收限制仍保留文字，可手动继续。不能改写第三方 DLL 的优先级或依赖图，不提供实际加载排序写入。
- 游戏内观测、存档隔离和自动更新继续延后。在线浏览与手动确认版本替换按本轮用户要求新增，不代表后台自动更新已实现。
- WebView 主程序退出后曾复现两子进程残留；旧 FAIL 保留，间歇性根因尚未定位。极端 Environment.FailFast 系统弹窗和实际文件符号链接负例的权限缺口也保留，本轮不重跑这些专项。
- 当前没有新的人工/DPI 结论；历史用户结果不继承到新版本，本地自动检查不替代人工或系统 DPI 验收。
- 运行中检测仍有历史特殊进程场景缺口：改名或已删除映像的硬链接、非主映射句柄及部分原生查询竞态可能漏检，ACL 限制状态分类也未满足旧测试。本轮相应守卫回归保留 8 个失败；正常退出游戏后再保存，不依赖管理器结束或识别特殊启动器进程。

首版不增加 G0–G5、AI 或人工放行前置。上述结果是各次本地检查的范围；源码公开不代表已发布或验收便携二进制版本。

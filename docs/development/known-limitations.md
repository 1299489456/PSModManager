# 当前已知限制

当前版本面向 Probably Stolen 正式版的原生 Mono 模组。游戏自带加载器负责加载；管理器在显式保存时按清单与声明 DLL 指纹写入用户启用批准，不修改游戏 DLL。普通保存和启动不自动扫描，批准不是安全审计。不安装 MelonLoader，不使用 Nexus，也不分发 Cpp2IL 或 Unity 生成依赖。

## 安装、顺序与运行

- 本地导入接受包含 `manifest.xml` 和声明文件的完整目录 / ZIP，不接受旧版裸 DLL、安装脚本、RAR/7z、加密包、链接、危险路径或大小写冲突。最多 4000 个文件、单文件及 ZIP 64 MiB、包内容总量 256 MiB；同 ID 已存在本地包时不静默覆盖。
- 导入预检检查清单、路径及程序集 PE/CLI 头，不执行 Mod DLL；它与顶部独立“模组检查”页的全包分析分开。声明权限、启用批准和历史检测证据不能冒充当前内容已检查。
- “已安装”“目标启用”“原生批准”和“运行记录”分别记录。启用不弹管理器权限框；显式保存记录当前来源、清单与声明 DLL 的批准。未检测权限保持未知，不用声明权限填充检测结果。包缺失、依赖冲突、运行中和写入保护继续生效。
- 排序保存 `modOrder`，校验已知依赖和自定义先后规则。当前游戏先加载 DLL 再应用顺序，不能保证 `Init`、Harmony 或 Hook 的初始化先后，也不能解决所有玩法冲突。
- 运行记录来自最近 `Player.log` 中实际报告的入口，不代表实时进程或所有入口均加载成功。没有日志、日志过旧或覆盖不完整时不能证明本次运行成功。
- 同 ID 的本地来源可能遮蔽工坊来源；工坊更新成功不代表游戏使用的就是该副本。先核对详情中的实际来源和版本。

## 手动模组检查与可选 AI

- 普通页面和启动不请求检查接口；进入顶部“模组检查”页才读取检查记录，明确点击后才扫描。已经主动开始的检查可继续执行，不因离开页面伪装成完成。
- 基础检查不执行候选 Mod、不调用 AI、不上传第三方信誉服务。程序集的静态解析在无能力 AppContainer 中执行；隔离不可用、超时、超限或解析缺口均显示检查未完成，不降级到普通进程当作成功。
- 报告绑定安装、来源、全包内容和规则版本。未知、过期、未完成和高风险报告供用户复核，不自动阻断普通启用、保存或启动。只在用户主动请求时扫描全部或选定模组，显示实际进度与覆盖缺口。
- 静态 API 引用、字符串或行为组合是审查证据，不证明实际执行；反射、混淆和动态内容仍可能隐藏行为。大文件、联网、P/Invoke、Harmony 或未签名不独立判定恶意，“未发现高风险项”不是安全认证。
- 手动检查不会删除、停用模组或写入批准。停用、隔离和恢复需要明确操作；主动隔离及未完成处置继续限制相关操作。工坊隔离不改变 Steam 文件或订阅，本地隔离使用原生恢复点；恢复不自动启用或恢复批准，重新检查不是强制步骤。
- 隔离限制只覆盖管理器能够控制的操作，不能阻止外部 Steam/EXE 启动，也不能保证启动后文件不被其他进程修改。隔离不能撤销已经执行的代码、外部文件变更或账号泄漏。
- Defender 仅在显式请求时参与，引擎缺失与未扫描分别显示。管理器不主动上传样本，但 Defender 自身云策略受系统设置管理；没有引擎检测结果不等于无风险。
- 可选 AI 使用现有日志分析 Provider，仅在用户预览实际消息并再次确认后调用。报告摘要上限 24 KiB，最多 16 条发现、8 个程序集与 8 个大文件；普通发现每条最多 3 处定位，用户聚焦的发现每条最多 12 处。截断明确标记，不含 DLL 原始字节、反编译源码、完整文件清单、哈希或批准数据。AI 可能出错，不修改检查结论、批准或处置状态。
- AI 预览仅保存在内存，最多 16 份、10 分钟；报告或分析服务变化后需重新预览，失败/取消也不自动重试。重复发送同一预览复用原任务，普通管理和本地检查不依赖 AI。
- 当前未提供第三方信誉查询或可疑代码动态试运行，不执行 AI 提供的处置指令。

## 写入、方案与恢复

- 游戏运行中或无法可靠确认停止时，允许编辑草稿，不写入游戏状态、配置或包。特殊启动器及改名进程仍需谨慎，保存前正常关闭游戏；管理器不会强制结束未知进程。
- 原生写入检查并发版本、建立恢复点并保留未知配置字段。检测到外部修改、权限不足、文件占用、空间不足或待处理恢复事务时停止相应动作，不把失败当成功。
- 多个安装共用应用数据时，恢复检查核对历史记录归属；可验证属于其他安装的记录不会占用当前安装。当前安装未决记录、损坏或归属无法验证的记录仍阻止相关操作，不以删除记录解除保护。
- 不识别的 ES3 编码或类型结构只读报错，不尝试转换猜写。配置缺少运行时类型定义时按字符串编辑，不推测开关、数值范围或删除遗漏键。
- 恢复点覆盖对应状态、配置或本地文件操作，不等于完整游戏或存档备份，不恢复历史批准，也不让已被 Steam 更新的工坊文件回到旧版本。异常断电后仍需核对实际文件与恢复记录。
- 原生方案保存 ID、启用顺序、规则和来源信息，不携带账号授权、游戏批准或存档。导入方案不会自动安装缺失包；旧版方案只能预览迁移，未明确匹配原生 ID 的项目不会按相似名称猜测执行。
- 应用数据与程序分开；同机数据迁移保留原目录，Windows 凭据通过专用接口迁移已记住的 AI 密钥。手动复制目录不等于跨电脑凭据迁移或一键恢复全部游戏数据。

## Steam 与 AI

- Steam 订阅及下载由官方客户端处理，管理器不手写 ACF 或工坊包。直接操作需要可用的本机已登录 Steam 会话和本游戏接口；失败时显示原因，保留官方页面入口，不索取 Steam 密码。
- 直接操作限于所选 Steam 库安装；手动原生安装仍可本地管理和启动游戏，但不能借此修改工坊。会话依赖当前游戏的签名 DLL 与接口版本，不兼容时明确拒绝。
- 订阅确认、下载请求被接受、下载完成和本地安装完整是不同状态。没有可靠逐项进度时不补百分比；匿名下载不等于账号订阅，本游戏未验证的匿名下载能力保持不可用。
- Steam 后续可能自行下载已接受的任务；关闭管理器不等于取消 Steam 队列。启用列表、原生恢复点和方案不能冻结客户端更新。
- “管理器自动更新模组”默认关闭，只约束管理器主动发出的更新请求；不能永久关闭 Steam 客户端自己的更新。待更新数量变化不等于管理器自动发起过下载。
- 超时或会话丢失后，已提交但尚未确认的操作显示结果待确认，不自动重放。刷新核对前会阻止重复请求、游戏启动及数据迁移；Steam 的活动下载也会阻止从管理器启动游戏。
- Steam 只读会话也使用本游戏 AppID，实测可短暂改变 Steam 的 Running 标志；客户端界面的显示及延迟尚未单独量化。卡片和详情不初始化 SDK，后台状态探测完成即关闭会话，启动游戏前释放。
- 公开工坊列表依赖 Steam 页面及公开接口，与账号会话状态分开。筛选、搜索和翻页立即返回缓存或加载状态，后台请求仍可能因网络或页面变化失败；目录过期不代表账号断开。条目依赖只展示有来源证据的内容。
- 元数据、封面和完整译文可跨重启复用；缓存不包含凭据，也不能替代当前账号、下载和运行证据。介绍或服务配置变化可能使译文缓存失效，失败和取消结果不当作完整译文。
- 公开缓存最多 128 条元数据、64 张图片，单图 1 MiB；未访问过的条目在离线时无法加载。译文另有 16 MiB 上限，不自动淘汰已有译文；读写失败明确提示，不静默重新调用付费服务。
- AI 是可选服务，翻译与分析只在用户主动操作时发送资料。介绍可能截断，译文会保留范围提示；外部服务可能收费、超时或产生错误内容，不能把译文当作作者原文或安全保证。

## 交付与验收范围

- Windows 10/11 x64、.NET Framework 4.8+ 和 WebView2 Runtime 是运行前提，管理器不会静默安装。便携包自带 Python 与元数据 helper 的 .NET 运行时，不附带游戏的 Steam API DLL 或客户端文件。
- EXE 未作发布签名；下载后完整解压，不混用不同版本的 EXE 和 `_internal`。本地产物不等于已发布版本。
- 解压新包不会替换已运行的旧窗口。保留未保存的选择并正常退出旧版后，从新目录启动，在标题栏或“应用信息”核对 0.3.5；旧快捷方式仍可能启动旧目录，程序不代替用户结束旧进程。
- 每次候选的接口检查、真实只读数据、账号订阅写入、外部 AI、源码 WebView、冻结 EXE 和干净机器结果分别记录。不把历史截图或模拟回调继承为新候选的实际验收。
- 未提供存档管理、后台自动更新管理器、任意 shell AI 或对所有真实 Mod 的兼容保证。原生批准按已核对的当前游戏协议写入；官方信任列表、程序集兼容、入口初始化、玩法和存档兼容仍由游戏实际运行决定，不能由批准成功保证。

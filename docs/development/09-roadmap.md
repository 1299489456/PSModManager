# 开发路线与功能依赖

2026-10-12 调整：这是本地 Mod 管理器，首版围绕选择游戏、导入、安装、启用、停用和卸载。启动和 AI 为可选帮助；不要求用户管理 Profile、批准计划或处理恢复历史后才能安装 Mod。

保留原37项 ID 和任务卡用于追溯，全部完成不是首版要求。现有复杂守卫、ActionPlan、journal 和恢复历史属于内部复用能力，不追加为普通用户流程。PS-03-07 已接通直接操作；状态、当前验证与历史结果见 [台账](task-register.json)。

## 历史阶段检查索引

G0–G5 只用于定位旧开发记录；不是审核流程、产品页面或任务前置。历史 PASS/FAIL/BLOCKED/NOT_RUN 保留，不因为取消门禁而改为通过。

首版判断依据是当前安装、启停、卸载的实际行为和针对性测试；启动按需选做。人工体验反馈用于修复具体问题，不构成独立开发的放行条件；真实游戏、干净机器和联网只记录已经执行的范围，没有环境也能完成不依赖它们的本地开发。

# 产品范围与需求

版本：2.0；2026-10-12 按用户要求收缩。产品是本地 Mod 管理工具，可选嵌入 AI；不按高可靠部署平台设计。

## 1. 核心功能

- 选择游戏目录，显示可管理的 Mod。
- 从 DLL、目录、ZIP 添加 Mod，并点击一次安装。
- 直接启用、停用、卸载所选 Mod；用户主动选择时可清空 Mod 目录重新安装。
- 显示当前操作进度、实际结果和直接可理解的错误；失败可以重试或重新安装。
- 在用户要求时保留一份简单备份或恢复最近备份。没有备份时明确说明，不把普通管理操作锁进恢复审批流程。

普通安装不要求先创建 Profile、完成兼容图审核、批准 ActionPlan、核对历史代次或进行游戏玩法验证。批量清空、覆盖用户已编辑文件等有明确影响的动作可给一次普通确认，不增加多级审批。

## 2. 可选与排除范围

可选：组合方案、配置编辑、版本提示、日志查看、游戏启动、简单备份、AI 问答与建议。AI 不可用、未配密钥或断网，仍可管理本地 Mod。

首版不要求：多代回退平台、审计/恢复问题台账、HMAC 批准机制、全局进程身份与锁证明、每个持久化点强杀测试、断电或物理磁盘满验收、分阶段人工放行。

不做：通用游戏平台、商城、任意 shell Agent、自动修改系统运行时/加载器、正式存档管理。在线下载、游戏内探针、存档实验和自动更新保持延后。

## 3. 当前实现与待做接线

PS-03-07 复用包库、planner/executor 和守卫，默认 Mod 列表通过普通动作 API 直接安装、启停和卸载。用户无需创建 Profile 或批准计划；原方案和历史放在可选页，继续保留其原接口。清空目录、覆盖用户外改及 AI 接线未由本卡新增。

PS-03-04 的旧范围 BLOCKED 和失败测试保持历史事实，但不再阻挡核心安装接线；配置适配器、启动分层验证也不是其前置。旧结果不能用于宣称新的一次点击流程已经通过。

## 5. 基本操作边界

目标限于管理器支持的 Mod 目录（当前为 Mods、Plugins、UserLibs）；停用位置在加载器扫描范围外。路径不对、文件占用、空间不足或读取失败，直接提示具体问题，不改系统策略、不强制结束未知进程。

用户接受装错后删除 Mod 或重新下载游戏，不再以极端故障保证扩大首版范围。开发仍默认合成安装、隔离数据根；真实游戏、正式存档和原 RimCrow 的原有资源授权边界保留，适用授权不重复询问。

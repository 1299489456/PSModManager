## 实现步骤

1. 只读探测实际存档与配置写入，核实Steam Cloud和游戏启动参数/锁，不照搬RimWorld。
2. 使用用户批准的可丢弃存档和完整备份证明隔离机制，无法证明则保留仅提示/备份。
3. 建立隔离配置切换/恢复/云回写冲突策略，任何破坏性步骤须具体授权。
4. 记录内容模组迁移限制，禁止自动打开唯一正式存档做试验。

## 验收标准

1. 两个配置存档写入边界通过真实证据证明，否则功能不得标可用。
2. 云同步状态未知时不宣称隔离；不自动关闭用户云同步。
3. 失败可恢复测试数据，不修改正式存档。

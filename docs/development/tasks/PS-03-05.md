## 目标与实际消费者

可选的已知配置字段编辑器。没有配置适配器时，导入、安装、启停、卸载和启动仍可交付。只处理明确支持的格式；一般用户可继续使用 Mod 自带配置或外部编辑器。

实际消费者为顶栏“配置”弹窗 → `config.read/save` → `ConfigService` → 合成安装的真实文件。WallpaperFit 为 cover/fit/stretch，WallpaperBrightness 为 0–100 整数，LogToFile 为布尔值。格式依据原 [G7 样本](../../evidence_appendix.md)，不把 `.cfg` 一律当标准 TOML。不提供其他配置文件或 WallpaperFile、进度字段的任意编辑。

## 实现步骤

1. 只处理已选定的 PSWallpaper 字段；保留未知字段、注释、空白、换行和 UTF-8/UTF-8 BOM/带 BOM 的 UTF-16 编码，不新增通用配置平台。
2. 保留未知字段、注释、编码和原值；不能可靠往返时给出只读或外部编辑提示。
3. 保存前比较读取时的文件摘要，外部修改要求重新读取；可选备份位于管理器私有 `config-backups/<installation_id>/PSWallpaper.cfg`，只保留上次保存前的一份原文件。普通保存不需要独立 ActionPlan 审批。
4. 与当前代码需要的写入入口作最小接线，不引入混合 DLL/配置事务作为本卡必需范围。

## 验收标准

1. 支持字段能保存并重开，其他字段不丢失。
2. 无法解析或文件正在被使用时有直接错误，不擅自重写未知配置。
3. CASE-035 按本卡选定格式验证；全量保真格式矩阵与混合恢复实验不作为普通安装前置。

## 验证内容与命令

- tests/unit/test_config_adapters.py：本次选定格式和字段、未知字段保留与保存后重读。

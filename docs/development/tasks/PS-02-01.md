## 实现步骤

已有实现背景，仅在修复相关问题时参考；不是重新建设或扩大首版范围的指令。

1. 建立按SHA256寻址的不可变artifact库和package/release/component映射。
2. 已有文件先external登记；完整只读扫描形成BaselineSnapshot，确认清单后复制至库并校验，不移动游戏文件，不伪造已提交generation。首次部署用完整快照作基线，部分扫描不得成为可写基线。
3. 区分代码/资源、共享配置、业务数据、生成物和unknown，所有权按文件确定。
4. 相同内容去重但保留来源/版本记录；包库删除显式操作，不设自动LRU。

## 验收标准

以下保留原功能语义供相关回归参考。当前只验证受到本次修改影响的真实行为，人工/实机/DPI 和复杂故障矩阵不作为下一功能开发条件。

1. 接管取消、复制失败和重复接管可恢复且不改游戏；未知目录不被整包认领。
2. 同文字版本不同hash为不同release；共享资源所有owner可追踪。
3. 无硬链接污染：修改游戏副本不改变包库；库内坏hash被发现。

## 实现步骤

已有实现背景，仅在修复相关问题时参考；不是重新建设或扩大首版范围的指令。

1. 设置 PSModManager 应用名称、data root、日志、配置、数据库和 keyring service；默认不迁移 RimCrow 数据。
2. 建立惰性 composition；导入模块不扫描、不联网、不创建真实游戏文件；断开 Workshop/SteamCMD/旧更新器/旧路径迁移的启动调用。
3. 复用最小布局与资源，关闭 browser RPC 和远端 WebView bridge；外链交给系统浏览器。
4. 消除 build/prebuild 隐式 uv 同步，环境缺失给出明确提示；测试 data root 必须隔离。

## 验证内容与命令

- tests/unit/test_app_identity.py：独立路径、导入副作用、禁用旧更新器、冲突根拒绝。
- 桌面手动烟测：隔离 root 下启动/关闭并记录窗口、数据文件及网络访问结果。

适用 Profile：synthetic、desktop-local。仅运行本次需要且已有入口的路线；真实资源和联网路线按现有授权选择，不是独立本地开发的必经步骤。缺工具或入口如实记录，不自动安装。

```powershell
.\.venv\Scripts\python.exe -m pytest tests/unit/test_app_identity.py -q
.\.venv\Scripts\python.exe main.py --psmm-data-root (Join-Path $PWD '.dev-data/identity')
```

上述直接入口用于统一runner建立前；PS-00-05负责收编。测试应自行使用临时目录，桌面参数由PS-00-02提供。

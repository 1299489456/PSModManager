## 实现步骤

1. 复用 RimCrow 流式会话的适用部分，移除 RimWorld 提示词与无关工具初始化，不扩建会话审核系统。
2. 设置供应商、模型和 API key；需要保存时使用独立 keyring 服务，失败明确提示或仅在本次会话使用，不静默写明文。
3. 用户选中问题或日志后发送必要文本，过滤 token、代理认证等敏感内容，简短说明供应商；不要求逐个选择内部证据 ID。
4. 无 AI 配置时普通 Mod 管理照常工作；连接测试仅在用户点击时进行，首次启动不自动联网。

## 验收标准

1. 原 RimCrow 凭据不自动读取或迁移；日志、导出、错误详情不泄露密钥。
2. 合成 provider 的流式会话和普通错误在实际 UI 可见，未配置或断网不影响本地安装、启停和卸载。
3. 默认只发送当前问题需要的文本与元数据，不上传完整 DLL、存档、全部日志；发送范围不变成安装审核前置。

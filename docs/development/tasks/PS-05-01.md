## 实现步骤

1. 用代表性本地 Mod 数量检查列表、搜索、按钮反馈和操作完成时间，记录环境和明显卡顿。
2. 检查当前窗口尺寸、键盘操作、中文路径和重开；发现具体问题再补相关 DPI 或规模测试。
3. 只修受影响瓶颈和交互，不重做底层守卫、恢复历史或无关功能。
4. 运行基础管理受影响回归；AI 只在已实现且本次需要交付时检查。

## 验收标准

1. 普通安装、启停、卸载可操作，错误和结束状态清晰，没有持续 UI 阻塞或后台遗留。
2. 主要按钮与键盘操作可达，文字和错误提示可读。
3. CASE-045 原5000组件及125/150/200%DPI为可选基准，不要求全套人工检查才进入打包；没有做的测试不称已通过。

## 验证内容与命令

- 实际测试目录存在时，选择 `tests/performance/` 和 `tests/desktop/test_accessibility.py` 中相关检查。
- 无既有入口时创建针对主流程的最小测试；不为性能烟测新增依赖。

适用 Profile：synthetic、desktop-local。

```powershell
.\.venv\Scripts\python.exe -m pytest tests/desktop/test_accessibility.py -q
```

已有映射时可用：

```powershell
pwsh -NoProfile -File scripts/verify.ps1 -Task PS-05-01 -Profile synthetic
pwsh -NoProfile -File scripts/verify.ps1 -Task PS-05-01 -Profile desktop-local
```

缺少文件或映射不运行空检查，只在实施本卡时补充相关入口。

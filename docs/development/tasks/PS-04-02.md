## 实现步骤

1. 接入 05 所列必要查询，返回名称、版本、相关日志和可理解摘要；内部来源信息按需保留，不强制用户审阅。
2. 使用固定工具表和普通参数校验，核对当前安装/Mod/日志 ID，并复用输出限制、超时和取消处理。
3. 拒绝不存在的工具、额外字段、任意 shell、任意删除目录和越界对象；不为模型提供自由文件路径操作。
4. 用日志或 Mod 说明中夹带命令的场景验证：这些文字只是资料，不能改变工具边界，不新增独立角色或审批层。

## 验收标准

1. 模型返回未开放工具名、无效对象或任意命令时收到普通错误，不能执行隐藏入口。
2. 配置查询只读已支持的必要字段；不读取或修改正式存档，不把备注当游戏状态。
3. 工具输出与时限有界，错误可理解且不泄露密钥；手工管理 Mod 不依赖这些查询成功。

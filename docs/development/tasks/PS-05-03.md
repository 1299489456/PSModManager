## 实现步骤

1. 运行实际打包产物，记录 Windows/WebView2 等必要环境，不用源码 main.py 代替。
2. 用合成安装完成导入、安装、启停和卸载，数据根与程序文件分开。
3. CASE-048 仅在有旧版数据时检查普通迁移和备份恢复；不为首个便携版本创建庞大升级/回退矩阵。
4. 有干净 VM 或另一机器时补检查，缺环境记清限制，不自动安装运行时或创建额外环境。

## 验收标准

1. 缺运行时给出可理解提示，普通用户操作不依赖管理员权限；没有隐式安装。
2. 实际产物的 UI、helper 和基础文件动作可用；开发机结果仅代表该环境。
3. 退出或卸载管理器不删除游戏、用户配置和包库。CASE-047/CASE-048 只覆盖实际使用环境及已有迁移范围。
